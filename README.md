#  電信客戶流失預測與 XAI 商業留存策略報告

## 📌 專案背景
在電信產業中，獲取新客的成本遠高於維繫舊客。本專案不只停留在「預測誰會流失」，更進一步導入 **模型可解釋性** 技術，打破機器學習的黑盒子，精準量化各項特徵對客戶決策的影響力，進而轉化為具體的行銷留客策略。

## 技術
* **語言與開發環境:** `Python`, `Jupyter Notebook` 
* **資料處理與視覺化:** `pandas`, `matplotlib`, `seaborn`
* **機器學習與不平衡處理:** `scikit-learn` (Random Forest), `imblearn` (SMOTE)
* **模型可解釋性:** `SHAP` (SHapley Additive exPlanations)

## 核心亮點與商業價值

* **1. 高效召回潛在流失客:**
  面對真實世界中資料高度不平衡的挑戰，引入 SMOTE 過採樣技術。模型不僅達到 76% 的整體準確率，更在流失客群中取得優異的召回率 ，確保行銷資源能精準攔截潛在流失者。
* **2. 突破黑盒子：SHAP 歸因分析:**
  捨棄傳統的 Feature Importance，採用 SHAP TreeExplainer 進行微觀與宏觀分析。精準指出「光纖網路 (Fiber optic)」與「按月簽約 (Month-to-month)」是大幅推升流失率的兩大核心痛點。
* **3. 數據驅動的決策建議:**
  不再只交付程式碼，而是產出具備商業敏銳度的洞察報告。明確建議產品部門盤點光纖網路品質，並建議行銷部門針對「新手合約期」祭出精準留客方案。
